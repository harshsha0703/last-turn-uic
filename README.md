# Last Turn — UIC Campus Finder

Final submission source. Only East Campus buildings with submitted photo documentation are shown. The SCE Inner Circle route is the demonstrated three-step team-checked route. Other buildings have photo-based references and do not claim verified indoor turn-by-turn navigation. Not an emergency navigation tool.

## Deploy to Vercel

Upload the **contents** of this folder to your existing GitHub repository (do not upload this ZIP or node_modules). Vercel will automatically redeploy from main. Framework: Vite; build: `npm run build`; output: `dist`.

## Run locally

`npm install` then `npm run dev`.
